# I6：上下文工程概述

> Easy Data x AI 课程 · 产业应用篇 · 第 6 节

::: tip 开发状态
本节正在开发中，当前页面用于说明课程方向和共建边界。
:::

## 本节简介

本节解释上下文工程为什么不等于“把更多内容塞进提示词”。课程将从来源、记忆、任务状态、预算和引用出发，理解 Agent 在每次决策前如何获得足够、相关且可追溯的上下文。

## 计划内容

- Source、Memory、PreparedContext 与 Handoff 的职责边界
- 项目范围、相关性和上下文预算
- 检索、压缩、引用与冲突处理
- 上下文质量、延迟和成本之间的权衡

## 与现有课程的关系

P3、P4、D4 分别讨论记忆、知识和实现，本节把这些内容放进完整的上下文准备链路中理解。
