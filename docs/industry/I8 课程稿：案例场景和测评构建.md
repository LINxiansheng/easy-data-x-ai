# I8：案例场景和测评构建

> Easy Data x AI 课程 · 产业应用篇 · 第 8 节

::: tip 开发状态
本节正在开发中，当前页面用于说明课程方向和共建边界。
:::

## 本节简介

本节把前七节的能力放回真实任务：先定义场景和成功标准，再构建数据集、运行链路和测评记录。课程强调可复现证据，避免把单次演示或单个基准数字当成通用结论。

## 计划内容

- 从业务目标拆出任务、数据、约束和失败成本
- 检索质量、回答质量、延迟、成本和引用正确性
- 确定性回放、在线运行与离线重新评分
- 记录输入、输出、Memory、PreparedContext 和执行轨迹

## 与现有课程的关系

P5、D5 负责案例与度量的课程闭环，本节进一步补充产业场景的测评设计、证据边界和复现要求。
