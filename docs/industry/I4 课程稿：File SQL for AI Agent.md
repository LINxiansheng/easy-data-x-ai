# I4：File SQL for AI Agent

> Easy Data x AI 课程 · 产业应用篇 · 第 4 节

## 本节简介

本节探索 Agent 如何把文件转成可查询、可追踪的数据：从文件发现和解析开始，到元数据、正文片段、外表和 SQL 查询，再回到带来源的回答或工具调用。

## 计划内容

- 文件、目录、元数据和正文的建模方式
- 外表与即时文件查询的使用场景
- SQL、全文和向量检索如何协作
- 文件权限、来源引用和变更追踪

## 与现有课程的关系

P3、D4 讨论记忆系统，本节关注文件资料如何进入 Agent 的数据与检索链路。
