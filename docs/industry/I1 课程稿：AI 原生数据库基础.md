# I1：AI 原生数据库基础

> Easy Data x AI 课程 · 产业应用篇 · 第 1 节

::: tip 开发状态
本节正在开发中，当前页面用于说明课程方向和共建边界。
:::

## 本节简介

本节从 AI 应用的数据需求出发，认识为什么 Agent 不只需要保存业务表，还需要处理向量、全文、结构化和半结构化状态，并理解事务、检索和部署方式在 AI 系统中的作用。

## 计划内容

- AI Native 数据库与传统数据库、单一向量数据库的关注点差异
- Agent 状态、知识和业务数据的统一管理需求
- 嵌入式与服务器模式的使用边界
- ACID、可恢复状态与实验可复现性

## 与现有课程的关系

D2 负责带学习者跑通统一数据层，本节进一步解释这些能力在产业场景中的定位和边界，不重复 D2 的基础代码。
